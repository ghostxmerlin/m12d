# insightface genderage 验证（2026-11-09）

## 来源

- insightface 官方 release v0.7 的 `buffalo_s.zip`，sha256 `d85a87f5…8b5e`。
- 只取了其中的 `genderage.onnx`，sha256 `4fde69b1c810857b88c64a335084f1c3fe8f01246c9a191b48c7bb756d6652fb`，1,322,532 字节。
- 用 ncnn 6afc736 的 `onnx2ncnn` 转换，结果放在 `research/2026-11-09-genderage/genderage.{param,bin}`。

## 模型约定

- 输入 `data`：RGB，96×96。图里有 Sub/Mul，归一化已经包含在内。
- 输出 `fc1`：3 个值，前 2 个是性别得分（下标 1 是男性），第 3 个是年龄 ÷ 100。
- 下标 1 表示男性：测试者本人确认了自己的性别。
- 裁剪方式与 insightface 的 Attribute 相同：不做五点对齐，人脸框中心放到 (48,48)，框的长边乘 1.5 对应 96 px，越界部分填黑。

## 转换正确性

42 张裁剪图（21 帧，320 和 640 原图各裁一次），与 onnxruntime 对比：最大差值 0.00000，解码结果全部一致。

## 设备耗时

12.5 ms（2 线程，检测暂停时测）。对比：deepinx 模型 62 ms。

## 结果合理性

同一个测试者（男性），21 帧：

| | 从 320 裁剪 | 从 640 裁剪 |
|---|---|---|
| 性别 | 21/21 男，差值 3.7–8.5 | 21/21 男，差值 5.5–9.1 |
| 年龄 | 32–52 | 32–52 |
| 年龄段 | 21/21 adult（30–54） | 21/21 adult |

- 近距离的帧年龄偏大（47–52），远距离的偏小（32–36），但都落在同一个年龄段。
- 对比 deepinx 模型：同一个人被估成 13–41 岁，性别得分差值只有 0.05–2。

## 局限

只有一个人的样本，没有验证女性、儿童、老人。需要更多人测试。

## 结论

genderage 可以用于"性别加年龄段"。从 320×240 采集裁剪就够了。
