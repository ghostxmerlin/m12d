# Task 6：同一帧在主机和设备上的检测一致性

输入：`tests/data/face_640x480.yuyv`，由 M12 采集（单人正脸）。图片含人脸，不提交。
工具：`detect_file`，输出坐标按 640×480 计。

设备（armhf，ncnn NCNN_ARM82=OFF）：
```
face 345.009 136.283 96.917 119.390 0.992 369.289 177.032 410.057 172.751 389.252 193.486 375.569 220.679 409.197 217.215
```

主机（aarch64 容器，ncnn **NCNN_ARM82=ON**，即第一次构建）：
```
face 345.082 136.300 96.866 119.166 0.991 394.081 209.284 377.291 235.485 398.359 216.244 375.704 220.489 409.331 216.934
```
- 框和 prob 很接近。
- 但前 3 个关键点完全错乱。原因是 ncnn 6afc736 在 aarch64 上走了 fp16 路径。

主机（aarch64，ncnn **NCNN_ARM82=OFF**）：
```
face 345.009 136.283 96.917 119.390 0.992 369.289 177.032 410.057 172.751 389.252 193.486 375.569 220.679 409.197 217.215
```
与设备逐位一致：人脸数相同，坐标差 0.000，prob 差 0.000。

结论：主机版 ncnn 必须用 `NCNN_ARM82=OFF` 编译，否则 B 层的参照结果不可信。`scripts/build-ncnn.sh` 已经改好。
